# Security Policy

## Reporting a Vulnerability

Do not open a public issue for credential leaks, gateway bypasses, or prompt-injection escape vulnerabilities.

Report sensitive issues privately to the project maintainer through GitHub Security Advisories or a private communication channel.

## Scope

Examples of in-scope issues:

- OpenClaw token exposure
- session or archive data leaking credentials
- prompt-injection bypass that escalates trust from page content to system policy
- unsafe default configuration that exposes local services
