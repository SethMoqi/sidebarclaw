# Code of Conduct

## Our Standard

Be respectful, direct, and constructive.

Examples of expected behavior:

- giving clear technical feedback
- discussing tradeoffs without personal attacks
- assuming good intent while keeping a high quality bar

Examples of unacceptable behavior:

- harassment or personal abuse
- publishing private credentials or sensitive data
- hostile, discriminatory, or insulting language

## Enforcement

Project maintainers may remove or reject contributions that violate this code of conduct.
